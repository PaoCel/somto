Revisione commenti import

Commenti-episodio importati da TV Time, in coda di revisione. "Pubblica i risolti" li scrive sui thread-episodio pubblici a nome dell'utente (idempotente). Fai prima un'"Anteprima" per vedere quanti verrebbero pubblicati. Con "Mostra candidati" scegli i singoli commenti: pubblichi o scarti solo quelli selezionati (uno scartato non viene mai pubblicato, anche da "Pubblica i risolti"; si può ripristinare).

Nessun import con commenti in coda. Le code si popolano quando arrivano nuovi import TV Time con commenti-episodio.
